SimpleCADAPI 2.2.0b1 / OCP 7.9.3.1 中构建，参考 STEP 在独立 OCP 8 环境对账。

所有模型的最大相对体积误差为 `1.492e-6`，最大面积误差为 `1.092e-6`，
最大包围盒误差（相对于对应轴跨度）为 `2.778e-9`。均远低于 `1e-3` 的
验收阈值。原始报告在本机 `out/validate.json`，逐模型源码在 `out/ftc`，
输入特征图在 `out/traces`。这些运行产物被 Git 忽略。

模型 `46_tea_cup` 构建成功且全部基础几何检查通过，体积相对误差约
`1.45e-9`、世界包围盒一致。独立参考内核的 STEP 双向差集计算仍生成无效
拓扑，因此保留 `reference_error`，严格验收判为拒绝。没有跳过该模型、
改变差集门槛或把无效差集当作零。报告同时给出 `metrics_quality=accepted`
与 `quality=rejected`，批量 CLI 在这次严格验收中返回 1。

测试按先写断言再实现的方式推进，相关回归包括真实捕获、格式、几何、未知
API、孤立进程崩溃、超时、同体积/同包围盒但孔位不同的反例、图重放以及
既有 CQ / WHUCAD、草图、QL 测试。295 项相关用例通过，另有 35 个子测试。
六个真实图 fixture 保存在 `test/build123d_traces`，普通 CI 不需要 build123d。

203 个顶层导出、540 个去重公开成员的清单与样例证据在 `api_coverage.json`。
标为 `verified_sampled_usage` 的条目仅说明相应已验收样例使用过该 API，
不代表其全部参数组合或全部公开 API 都已通过转换。复杂曲面构造等未接入
边界在 [API_RESEARCH.md](API_RESEARCH.md) 和转换 meta 中明确列出。
