# 2.2.4 更新说明

编辑器现在会告诉你模型为什么没出来，而不是让"building the model"一直挂到兜底超时。

## 每次主动运行都会报告构建结果

以前同一条发布错误只报一次。当同样的失败再次出现时——再点一次"run all"、agent 改了一个 cell、
notebook 文件在磁盘上被修改——编辑器会保持沉默：模型不来，错误也不显示，页面只能等三分钟兜底。
现在每一次主动发起的运行都会重新报告结果，遮罩会随原因揭开（例如 notebook 顶层 Part 的 id 和
notebook id 不匹配；报错末尾会列出实际找到的 Parts and Assemblies）。拖 slider 过程中的重复
报告仍然按同状态折叠成一条。

在失败之后打开或刷新的页面，会在连接握手的末尾立刻拿到这条原因。
