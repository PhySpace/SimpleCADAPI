# 2.2.1 Update Notes

The first stable release of the 2.2 line. It brings the code-first editor, the
notebook runtime of 2.2.0b1 and the agent landing path to a stable version.

## Editor: `sca edit`

- A web editor over a directory of notebooks, part of the SDK
  (`pip install "simplecadapi[editor]"`). It runs the notebooks in a marimo
  kernel with the SDK's own cell executor, previews the live model straight
  from the solids, and shares one per-cell cache with `sca run`.
- Parameters from `# ---- params ----` cells (an optional `# ui:` comment picks
  the control); local modules (shared dimensions) have their own view.
- Picking a solid, face, edge or vertex writes a `scad.ql` selection cell
  (`selected_<kind>`, `selected_item`) into the notebook; edits autosave; a cell
  reference can be copied for a coding agent; `sca snapshot` shows an agent what
  the person sees. A log dock reports what ran and what failed.
- Light and dark themes (follows the system, with a manual switch).
- **Re-Studio is removed**: the reverse-engineering studio (`Re-mode` of the
  standalone sca-web-editor) is gone; `sca edit` replaces the standalone editor.

## Landing path for agents

`docs/landing.md` is the script an agent follows to install the SDK and its
skill and to open an example in the editor. `sca example u_link` copies the
bundled workspace; `sca skill where` shows where the skill is installed. The
wheel now carries the built editor UI, the skill sources and the example.

## Modeling

`scale`, affine `transform`, signed `offset`, `draft`, tapered and
until-limited extrusion and multisection sweep are recorded features. Volumes
and centres of mass integrate NURBS by knot spans, which is exact for rational
patches. A build123d to FTC converter is included under
`tools/research/build123dftc` (research tooling).
