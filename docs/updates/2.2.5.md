# 2.2.5 Update Notes

From a container agent's field report: the editor now works the way agents actually use it,
and says what happened instead of leaving silence.

## `sca cell` works behind container proxies

Before, a container's `http_proxy` swallowed the editor's health check and `sca cell`
answered "no editor is running" while one was. Now the editor's discovery record always
carries a loopback url (`--host 0.0.0.0` included), the checks bypass the proxy environment,
and a record whose server does not answer is reported with its path and url instead of being
skipped quietly. A record whose pid is gone says "stale record … delete it or restart the
editor". When `sca cell ls`/`get` fall back to reading the file, they say so on stderr.

## Cell feedback carries the chain

`sca cell put/insert/run` now return the console output and every cell left unhealthy by the
change, and the dependents a write made stale are run instead of waiting. A failing cell's
report names its upstream cells (the failing ones first), so the error you see can be traced
to its cause. A write whose rerun takes longer than the call now answers "the edit was
applied and the rerun is still going; check `sca cell ls`" instead of a raw socket error
(`SCA_EDITOR_CALL_TIMEOUT` raises the wait, default 300s).

## Validate a stage headlessly

```bash
sca run stage.py --through 3 --no-product    # the first 3 cells, no product needed
sca run stage.py --timeout 600               # a wall clock for heavy fillets
```

`--through N` runs the first N cells, numbered the way the editor numbers them; `--no-product`
runs a work-in-progress notebook that has no product yet; `--timeout` fails a run that takes
longer (off by default).

## Quieter output, shorter prints

The cache loaders' degraded-state warnings (unsigned entries, a value restored as a stub) no
longer print at WARNING, and the render paths switch VTK's warning display off process-wide —
this also hides VTK chatter from code you run in the same process. A real failure is still
raised and named. Printing a `BRepInspection` shows a one-line summary; the per-face records
are `to_dict()` / `.faces` / `.edges`.

## Skill

While an editor runs, `sca cell` is the only way to change a regular cell — the file only when
no editor runs, or for the setup / `@app.function` cells `sca cell` refuses. `dof=0` says the
constraint system closed, not that the shape is right (angle constraints can solve to the
mirror solution): verify by measurement. And a modeling project is managed like software:
git from the first file, commits at verified milestones.
