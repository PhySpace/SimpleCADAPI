# 2.2.8 Update Notes

This release brings the SDK what an editor and an agent need to work on a model that already exists: workplanes, stable
references, bodies that split and flow on, and edits to existing curves and surfaces. The editor gets a new viewport. Manual
modelling in the editor is built but not offered yet; this release ships the editor in code mode.

## Models you can point at

* **Workplanes are values.** `make_workplane_*_rworkplane` (from a face, points, an axis, a midplane, normal to a curve) and
  `make_workplane_offset_rworkplane` (moved and turned relative to a workplane or a named plane) are recorded and replay from
  model JSON; `make_sketch_rsketch(plane=wp)` sketches on one.
* **References are code.** `scad.ref` writes a readable, parseable reference to a face, edge, vertex or solid, and
  `ql.ref` uses one as a query predicate. A reference resolves through the recorded history (transform, scale, offset, draft,
  booleans), and a failing one reports its candidates and a repair.
* **Tags follow their entity.** A tag is a view over the recorded history. When a cut splits a body, the pieces are named
  `<tag>.split<i>` and a `TagSplitWarning` says so (also in `sca run` and the editor); fillet, chamfer and the other
  one-shape operations apply to every piece.
* **A Part holds one solid or several named bodies.** A cut that splits a body gives its pieces. `set_body_appearance_rpart`
  sets a body's display colour, opacity and name, and a face's name is a tag.

## Operations

* **Edit what exists.** `inspect_curve_rcurvedata` / `inspect_surface_rsurfacedata` read degree, poles, weights, knots and
  trimming; `set_*_poles`, `move_*_poles`, `set_*_weights`, `insert_*_knot`, `elevate_*_degree`, `convert_to_bspline_*` and
  `rebuild_curve_*` / `rebuild_surface_*` return a new shape, record a topology delta and replay. `sample_curve_rcurvature`
  and `sample_surface_risocurves` give an editor a curvature comb and isocurves.
* **Faces.** `press_pull_rsolid` pulls a flat face out (its prism joined) or presses it in (cut) with one signed distance;
  `inset_face_rsolid` imprints a face's loops moved inside it, so inset then pull builds steps and bosses without a sketch.
* **Sketch.** B-splines in the sketch editor, with trim, extend and crossings (also against ellipses);
  `fillet_corner_rsketch`, `chamfer_corner_rsketch`, `project_rsketch`, `trim_rsketch`, `extend_rsketch`,
  `diff_sketch_rsketchdiff`; the sketch's profiles and crossings come from the SDK (`inspect_sketch_rsketchprofiles`).
* **Assemblies.** `explode_rassembly`.
* **An edge is taken wherever a wire is** (a sweep path, a loft section, a face boundary): the wire of that one edge, recorded
  as `make_wire_from_edges_rwire`. `loft_rshell` of open sections gives the surface between two curves, and
  `sew_faces_rshell` takes faces and shells.
* **Every operation says what its parameters mean.** Signatures use typed meanings (length, angle, point, direction, count,
  selection, choice), and `simplecadapi.catalog` and `sca ops` read them straight from the bindings.

## The editor

* **A new viewport.** It renders with three's WebGPURenderer (WebGL 2 where WebGPU is missing, or with `?webgl`): one
  multisampled pass, ambient occlusion, edges drawn over faces with a depth bias along the view ray. A part seen up close is
  tessellated again by the kernel from its in-memory BREP (`POST /api/preview/refine`) until its chords are under half a pixel;
  parts several nodes draw are instanced; picks go through BVHs; surfaces are shaded from their exact normals.
* **English and Chinese**, following the browser unless chosen in the header.
* **Selections are `scad.ref` lines**, written into the notebook.
* **Code mode only.** Manual modelling (features, sketches and assemblies by buttons and dialogs) is built and kept in the
  tree, switched off by `MANUAL_MODE` in `editor-web/src/lib/manual-mode.ts` until it has a plan of its own. This release has no
  mode switch, command bar or manual keys.
* A notebook with no part yet is no fault: `find_product` raises `NoProductYetError` (a `ProductNotFoundError`), the editor
  previews an empty model, and `sca new` and the editor's *new* make an empty part notebook (the parametric cylinder is
  `--kind sample`).

## Behaviour changes

* `make_wire_from_edges_rwire` takes its edges in any order, and an edge that touches none of the others is an error instead
  of being left out. The error report of the face operations given an open or non-wire input is now the open-wire report with
  the measured gap.
* `sew_faces_rshell` raises `TypeError` for anything that is not a face or a shell.

## Fixed

* A stable reference into a face or shell body (no solid) resolves; it raised `cannot resolve QL selector scope`.
* A restored value counts a history-derived tag witness once; an input that stays in the result is preserved even when it
  also generates.
* A periodic B-spline's crossings are wrapped into one period before cutting.
* The editor page is served with no cache, so a rebuilt UI loads on the next visit.
