# 2.2.1 更新说明

2.2 系列的第一个稳定版。它把 code-first 编辑器、2.2.0b1 的 notebook 运行时和面向
agent 的落地路径带到稳定版本。

## 编辑器：`sca edit`

- 面向一个 notebook 目录的网页编辑器，是 SDK 的一部分
  （`pip install "simplecadapi[editor]"`）。它用 SDK 自己的 cell 执行器在 marimo
  内核里运行 notebook，直接由实体生成实时预览，并与 `sca run` 共用一份逐 cell 缓存。
- 参数来自 `# ---- params ----` cell（可用 `# ui:` 注释选择控件）；本地模块（共用
  尺寸）有独立视图。
- 点选实体、面、边或顶点会向 notebook 写入一个 `scad.ql` 选择 cell
  （`selected_<kind>`、`selected_item`）；编辑自动保存；可复制 cell 引用交给 coding
  agent；`sca snapshot` 让 agent 看到用户所见。底部日志面板显示运行了什么、哪里失败。
- 浅色与深色主题（跟随系统，可手动切换）。
- **Re-Studio 已移除**：逆向工程 studio（独立 sca-web-editor 的 `Re-mode`）不再存在，
  独立编辑器由 `sca edit` 取代。

## 面向 agent 的落地路径

`docs/landing.md` 是 agent 安装 SDK 和 skill、并在编辑器里打开示例时遵循的脚本。
`sca example u_link` 复制内置工作区；`sca skill where` 显示 skill 的安装位置。wheel
现在包含已构建的编辑器 UI、skill 源码和示例。

## 建模

`scale`、仿射 `transform`、带符号 `offset`、`draft`、带锥度和直到限定的拉伸、多截面
扫掠都成为可记录的特征。体积与质心按节点区间积分 NURBS，对有理曲面是精确的。
`tools/research/build123dftc` 下附带 build123d 到 FTC 的转换器（研究工具）。
