# 2.2.7 更新说明

C++ 引擎的第一个正式版（2.2.7b1 是 beta）：几何引擎是基于 OpenCASCADE 的 C++，随预编译 wheel 一起发布，
`pip install simplecadapi` 不再需要 `cadquery-ocp`，机器上也不需要装 OpenCASCADE。这一版让编辑器快了很多，让 `Var` 和 `Expr`
可以像数字一样使用，并补上了 beta 遗漏的东西。

## 预编译包

Linux x86_64 与 aarch64（manylinux_2_28）、macOS arm64（14+）、Windows x86_64，各支持 Python 3.10、3.11、3.12、3.13，
全部链接同一份 OpenCASCADE 7.9.3。macOS Intel、musl Linux、Windows ARM 没有预编译包；这些平台由源码包现场构建，
需要 C++20 工具链和 OpenCASCADE >= 7.8。

## 编辑器更快

六轴机械臂（`sandbox-envs/desktop_arm_sources`）在编辑器中的实测，同一台机器：

| | 2.2.6.post2 | 2.2.7b1 | 2.2.7 |
|---|---|---|---|
| 冷启动 | 64.5 s | 48.8 s | 34.9 s |
| 无改动启动 | 4.1 s | 2.1 s | 1.6 s |
| 一个没见过的关节角 | 4.4 s | 5.7 s | 2.7 s |
| 一个见过的关节角 | 6.2 s | 5.5 s | 0.6 s |
| 空闲内存 | 1038 MB | 322 MB | 617 MB |

* **模型更快到达页面。** 内核把模型发布成按几何内容标识的零件，服务器只给每个页面发它缺的零件，页面只为新零件建几何。
  改一个关节角只传 115 KB（原来 6.26 MB）；从最后一个 cell 到模型显示在屏幕上是 0.36-0.41 s（原来 1.3-3.2 s）。
  模型随 `preview` 事件直接经 WebSocket 推送，不再有第二次请求。
* **内核会记住 cell 的结果**和 `use()` 的返回值，保存的参数值的摘要只跟随 cell 真正读到的参数：改一个关节角不会再重做建零件的 cell。
  代价是内存：空闲时比 beta 多约 300 MB（内核保留最近的 12 个 cell 结果）。
* 仍有一个场景比 2.2.6 慢：机械臂上一个新的 `OPEN_STROKE` 值要 5.8 s（2.2.6.post2 是 4.7 s；beta 是 6.8 s），
  因为它触发的装配求解是真实的计算。

## `Var` 和 `Expr` 像数字一样工作

`int(r)`、`round(r, 2)`、`r > 3`、`max(r, 3)`、`sorted([...])`、`range(n)`、`[0] * n`、`lst[n - 1]`、`r // 2`、`r % 3`、
`f"{r:.2f}"`、`str(r)` 现在都可用，读取变量当前的值；算术运算仍然生成保留参数联系的公式。`r == 5.0` 为 `True`（原来是 `False`），
用 `Var` 算出来的值写 ql 谓词（`ql.prop("geom.length", ">=", 2 * math.pi * radius)`）现在能匹配，2.2.6 里匹配不到任何东西。
仍然报错的：`bool(var)`（请写 `if r > 0:`）和 `json.dumps(var)`；numpy 需要 `float(var)`。依赖新行为的笔记本不能原样在 2.2.6 上运行，
用 `float(var)` 可以保持可移植。

## `shape.wrapped` 是 OCP 形状

装了 OCP（`pip install "simplecadapi[verify]"`）时，`shape.wrapped` 是对应类别的 OCP 形状（`TopoDS_Solid`、`TopoDS_Face` 等），
用 OCCT API 写的验证脚本可以原样运行。它是一份拷贝：每次访问都生成新的，对它的修改不会影响 SDK 的形状。
`simplecadapi.verify.to_ocp` / `from_ocp` 是显式写法。`SCA_WRAPPED=native|ocp` 可以选择。没装 OCP 时仍是 SDK 自己的 OCCT 形状。
`fem` extra 已移除。

## 失败信息与修复

* fillet / chamfer 失败和 ql 的 `exactly()` 失败重新附带图片（2.2.7b1 只有布尔运算有）。
* 编辑器用磁盘上现有的模型文件启动：损坏或不完整的文件不会被恢复，也不会再让编辑器一直停在"starting the kernel"。
  损坏的预览会带着原因被拒绝（`400`），不再被当成缺零件。
* 旧版本写入的、指向已不存在的类的缓存条目会被替换；有这类条目的笔记本（通过 `use` 运行的子笔记本、机械臂的夹爪）
  耗时从 3-6 s 降到 0.8 s。
* 读取几何类型或封闭性时发生的 OCCT 失败会让该属性为"无"，与 2.2.6 一致。
* 过去被处理但不留痕迹的失败，现在会在 stderr 打印一行 `[sca]`。

## 升级须知

* **保存了参数值的笔记本在升级后会重建一次**（它们的 cell 摘要变了）。
* 装了 OCP 时 `shape.wrapped` 是拷贝（见上）。
* 新增的开关见 `docs/environment.md`。

## 面向贡献者

C++ 代码已统一格式（`.clang-format`，CI 检查），有 `CONTRIBUTING.md`、阅读顺序和合入计划（在 `src/cpp/` 下），容差有了名字（`scad::tol`），
clang-tidy 不再报告被吞掉的异常和未检查的 optional，doctest 可执行文件在 CI 中以 Release 以及 ASan、UBSan 运行。
不适用于软渲染器的旧测试列在 `src/cpp/docs/DEVIATIONS.md` 里。
