# 2.2.8 更新说明

这一版让 SDK 具备了编辑器和 agent 在“已经存在的模型”上工作所需要的东西：工作平面、稳定引用、会分裂并继续流转的实体，以及对已有曲线和曲面的编辑。
编辑器换了新的视口。编辑器里的手动建模已经做出来，但这一版暂不开放；本版本的编辑器只提供代码模式。

## 可以被指到的模型

* **工作平面是值。** `make_workplane_*_rworkplane`（由面、点、轴、中面、曲线法向）和 `make_workplane_offset_rworkplane`
  （相对某个工作平面或命名平面移动、旋转）都会被记录，并能从模型 JSON 重放；`make_sketch_rsketch(plane=wp)` 在其上画草图。
* **引用就是代码。** `scad.ref` 写出对面、边、顶点或实体的可读、可解析的引用，`ql.ref` 把引用当作查询谓词使用。引用会沿着记录下来的历史
  （变换、缩放、偏置、拔模、布尔）解析；失败时会报告候选项和修复方式。
* **标签跟着它的实体走。** 标签是记录历史之上的一个视图。切割把实体分成几块时，各块命名为 `<tag>.split<i>`，并由
  `TagSplitWarning` 报告（`sca run` 和编辑器里也会）；圆角、倒角等单形状操作会作用于每一块。
* **一个 Part 可以持有一个实体，也可以持有多个命名的 body。** 切割把 body 分裂时会给出各块。`set_body_appearance_rpart`
  设置 body 的显示颜色、透明度和名称，面的名字就是一个标签。

## 操作

* **编辑已有的东西。** `inspect_curve_rcurvedata` / `inspect_surface_rsurfacedata` 读出阶数、控制点、权重、节点和裁剪；
  `set_*_poles`、`move_*_poles`、`set_*_weights`、`insert_*_knot`、`elevate_*_degree`、`convert_to_bspline_*`、
  `rebuild_curve_*` / `rebuild_surface_*` 返回新的形状、记录拓扑增量并可重放。`sample_curve_rcurvature` 和
  `sample_surface_risocurves` 为编辑器提供曲率梳和等参线。
* **面。** `press_pull_rsolid` 用一个带符号的距离把平面拉出（并上它的棱柱）或压入（切去）；`inset_face_rsolid` 把面的环向内收缩后压印，
  先收缩再拉伸即可做出台阶和凸台，不需要草图。
* **草图。** 草图里支持 B 样条，带修剪、延伸和交点（也能与椭圆相交）；`fillet_corner_rsketch`、`chamfer_corner_rsketch`、
  `project_rsketch`、`trim_rsketch`、`extend_rsketch`、`diff_sketch_rsketchdiff`；草图的轮廓和交点由 SDK 给出
  （`inspect_sketch_rsketchprofiles`）。
* **装配。** `explode_rassembly`。
* **凡是要 wire 的地方也接受 edge**（扫掠路径、放样截面、面的边界）：取这一条边构成的 wire，并按 `make_wire_from_edges_rwire`
  记录。开放截面的 `loft_rshell` 给出两条曲线之间的曲面，`sew_faces_rshell` 接受面和壳。
* **每个操作都说明参数的含义。** 签名使用带类型的含义（长度、角度、点、方向、个数、选择、选项），`simplecadapi.catalog` 和
  `sca ops` 直接从绑定里读出它们。

## 编辑器

* **新的视口。** 使用 three 的 WebGPURenderer 渲染（没有 WebGPU 的地方用 WebGL 2，或加 `?webgl`）：一次多重采样的渲染通道、环境光遮蔽，
  边线绘制在面之上并沿视线方向做深度偏置。近处看一个零件时，内核会用内存中的 BREP 重新细分
  （`POST /api/preview/refine`），直到弦高小于半个像素；由多个节点绘制的零件会实例化；拾取走 BVH；曲面按精确法线着色。
* **中文和英文**，默认跟随浏览器，也可以在顶栏切换。
* **选择就是 `scad.ref` 行**，写进 notebook。
* **只有代码模式。** 手动建模（用按钮和对话框做特征、草图和装配）已经做出来并保留在代码树里，由
  `editor-web/src/lib/manual-mode.ts` 里的 `MANUAL_MODE` 关闭，等它有了自己的规划再开放。这一版没有模式开关、命令栏和手动快捷键。
* 还没有零件的 notebook 不算错误：`find_product` 抛出 `NoProductYetError`（是 `ProductNotFoundError` 的子类），编辑器预览一个空模型，
  `sca new` 和编辑器的“新建”会建一个空的零件 notebook（参数化圆柱改用 `--kind sample`）。

## 行为变化

* `make_wire_from_edges_rwire` 接受任意顺序的边，和其余边都不相接的边会报错，而不是被丢掉。面操作遇到开放的或不是 wire 的输入时，
  报告变成带实测间隙的“wire 未闭合”报告。
* `sew_faces_rshell` 对既不是面也不是壳的输入抛出 `TypeError`。

## 修复

* 对面或壳（没有实体）的稳定引用可以解析了；之前会抛 `cannot resolve QL selector scope`。
* 还原出来的值只计一次由历史得出的标签见证；留在结果里的输入即使同时也在生成，仍然保留。
* 周期 B 样条的交点在切割前先折回一个周期。
* 编辑器页面不再被缓存，重新构建的界面下次访问就会加载。
