# 2.2.2 Update Notes

Two additions to the code-first editor (`sca edit`), and a fix that made one of them usable.

## Code completion from the SDK

`scad.` (and `scad.ql.`, `scad.std.gear.`, `ql.`, `Q.`) lists the real functions with their
signatures; the side panel shows every parameter with its default and the docstring.

- Accepting a function, or typing `(` after a known name, writes the call with every
  **required** parameter as `name=`: `scad.make_box_rsolid(width=, height=, depth=)`.
  **Tab** moves to the next parameter.
- Inside a call, the parameters not given yet complete as `name=`, required ones first.
- The names come from the running package (`GET /api/sdk`), so they cannot drift from the code.

## Create a notebook from the workspace tab

A **new** action in the notebooks header starts a notebook from the SDK's template: a part, or an
assembly that uses the first two parts of the workspace. The name is checked as you type. An empty
workspace opens on that form, so `sca edit` on an empty directory is usable.

## Fixed

The cell editors rebuilt their configuration on every render, which dropped a snippet in progress
and could disturb typing; the editor's `onChange` and options are stable now.
