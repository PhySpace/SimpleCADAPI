# 2.2.2 更新说明

`sca edit` 编辑器的两项新增，以及一个让其中一项能正常使用的修复。

## 来自 SDK 的代码补全

输入 `scad.`（以及 `scad.ql.`、`scad.std.gear.`、`ql.`、`Q.`）会列出真实存在的函数和签名；
右侧面板显示每个参数、默认值和文档说明。

- 选中一个函数，或在已知函数名后输入 `(`，会把每个**必填**参数写成 `name=`：
  `scad.make_box_rsolid(width=, height=, depth=)`。**Tab** 跳到下一个参数。
- 在调用括号内，还没写的参数会补全成 `name=`，必填的排在最前。
- 名字来自正在运行的包（`GET /api/sdk`），不会和代码不一致。

## 在工作区页面创建 notebook

notebooks 标题处新增 **new**，按 SDK 模板创建 notebook：一个零件，或一个使用工作区前两个零件的装配。
边输入边检查名字。空工作区会直接打开这个表单，所以对空目录运行 `sca edit` 也能用了。

## 修复

cell 编辑器每次渲染都会重建配置，导致进行中的占位跳转丢失，也可能干扰输入；现在编辑器的
`onChange` 和选项都是稳定的。

完整列表见[更新日志](../../CHANGELOG.md)。
