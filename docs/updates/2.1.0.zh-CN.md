# SimpleCADAPI 2.1.0 更新说明

[English](2.1.0.md)

> **发布提示：** 用于生产前，请验证生成的定义、装配约束和制造几何。

SimpleCADAPI 2.1.0 把 SDK 推向 agent-first CAD 工具箱：Feature Tree
Convention 建模纪律 + 编译器校验的 skill 指引、外部 CAD 历史导入、浏览器内
逆向工作台、DXF 工程图、自包含可运行示例——全部建立在 2.0.4 beta 周期落地的
可复现产品边界与崩溃安全缓存之上。

## 1. 持久零件与装配定义

`@scad.part` 构建且只构建一个物理单实体零件，返回 `PartBuildResult`：运行时
`Part`、`PartDefinition`、图和 session 状态、model/session JSON、接口差异以及
单次构建的 `CacheReport`。内容派生 key 覆盖规范化参数、builder 源码、声明的
文件输入、revision、容差 profile 和 generator/ABI profile。

`@scad.assemble` 要求显式传入外部 `PartDefinition` 或嵌套
`AssemblyDefinition`。重复实例共享不可变定义；封闭校验会拒绝缺失、未使用、
循环、冲突或不兼容引用。定义可脱离进程内运行时对象独立往返。connector 接口
哈希跨进程稳定，相同接口不再产生虚假定义差异。

## 2. 增量装配求解、缓存与诊断

装配状态记录组件依赖和公共 connector 接口；变化只沿受影响的依赖路径传播，
每个恢复位置仍必须先通过约束残差验证。共享内容寻址存储使用规范封闭 record、
SHA-256 object、原子写入、逐 key 锁、陈旧锁恢复和对象去重。一个 `CachePolicy`
（`off` / `read_only` / `read_write` / `refresh`）同时治理零件与装配缓存，
`simplecad-cache` CLI 输出稳定 JSON 的 status 与 verify/repair 报告。

## 3. Feature Tree Convention（FTC）

模型源码遵循显式特征块纪律——sketch/profile、操作、布尔、修改器——以可读的
数据流记录（`body = op(body, tools)`），每个特征带头部注释
（`# ---- feature: <slug> (<role>) ----`）。该纪律由以下部分支撑：

- 约束 2D 草图 API（尺寸驱动轮廓、面向等壁结构的 wire 偏置），开链可提升为
  wire；
- 平面 maker 的规范平面/轴向约定，带回归测试覆盖；
- 经过验证的 QL 选择 playbook（33 个已验证选择模式），沉淀结构化选择通道及
  其覆盖范围。

## 4. DXF 工程图

确定性 DXF 引擎通过 HLR 投影把建模零件变成 2D 工程图：SheetPlan、视图、尺寸
链与诊断图，与 3D 导出器共用同一 package 管线。

## 5. 外部 CAD 历史导入

`tools/research/histjson` 加上 SDK 翻译层把外部 CAD 历史（Fusion 系）导入为
FTC 模型源码：约束无条件翻译，逐条输出冲突审计而不是静默回落。在参考基准上，
深多特征案例以机器精度复现几何（Deep ~85%、Fusion ~77% 全等），约束通道约
90%（Deep）/ 93%（Fusion）可解。

## 6. 浏览器内逆向工作区

统一 Web Editor 包含 Re-mode 工作区：在目标 STEP 上点面/点边或套索圈选，
用内联实体与操作 chip 做标注并提交。服务端组装 `submission.json`（标注 +
逐实体一级邻接上下文 + 操作提示 + 截图），agent 重建，UI 回流对比与评审。
输入框对输入法安全（CJK 组词期永不提交）、同一操作提示可引用多次，用户的
选择集合永不截断。工作区 UI 用 React 19 + Tailwind 4 + shadcn 风格组件构建，
命令式 three.js 内核保持不变。

配套的 `.scadpkg` 浏览器检查器加载 v3 包并做全闭包哈希校验，被篡改的包会
按成员点名拒绝。

## 7. 统一渲染与 FEM 就绪导出

一条截图管线覆盖全部 3D 出图需求：1–4 视图网格、studio 风格、确定性抗锯齿、
逐视角标注放置与遮挡处理。AP242/Gmsh 示例把同一 package 串过 AP242 STEP、
Gmsh 体网格与 Calculix 静力求解并输出 von-Mises 报告；MJCF 导出覆盖 MuJoCo
装配消费者。

## 8. 开源就绪

- 许可证从 AGPL-3.0 改为 Apache-2.0。
- 打包 skill 从单一源码树按 host harness 条件编译（omp、opencode、zcode、
  claudecode、codex、dsh、kimicode）；目标名拼写错误会让构建直接失败。
- 示例是自包含目录（源码 + 验证脚本 + `examples/<name>/out/` 下最新产物），
  覆盖零件 / 装配 / 逆向 / FEM 四类，且每个例子都验证过端到端可运行。
- `scad.verifier` 与 `python-fcl` 依赖移除；碰撞验证外置于 SDK。

## 9. 可靠性

几何指纹在 BRep 序列化往返下保持稳定（bounds 在固定 1e-4 mm 网格上量化，
远粗于亚容差的重算抖动），包重开校验不再在格边界几何上失败。Python 类型
检查基线下降一个数量级，测试套件在 Python 3.10–3.13 上共 1503 个用例通过。
