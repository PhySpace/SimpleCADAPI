## Import Surface

- top-level: `from simplecadapi import canonical_unit_for_dimension`

## Description

Return the canonical unit used by CAD and tolerance calculations.

Length, area, volume, and angle use ``mm``, ``mm^2``, ``mm^3``, and ``deg``.
